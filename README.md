# TL3B Website

Official website for TL3B, the padel match organizing app.

## Pages

- `/` - App information and feature overview
- `/privacy` - Privacy Policy
- `/terms` - Terms of Use
- `/support` - Support and release policy links

## Development

Requires Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

## Validation

```bash
npm run build
npm test
npm run lint
```

## Release Notes

Use `/privacy` as the privacy policy URL for App Store Connect and Google Play.
Use `/support` for app support and review contact information.
